# Radicon Laboratories Ltd

Live Website: https://www.radiconlab.com/

## Overview
Modern pharmaceutical company website built using Next.js, NestJS, TypeScript, Tailwind CSS, and MongoDB Atlas.

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- NestJS
- TypeScript

### Database
- MongoDB Atlas

## Features
- Responsive Design
- Product Management
- Contact Forms
- SEO Optimized
- Admin Panel
